# Café Charm – förslag på ny startsida

Demo av en ny startsida för Café Charm i Sundsvall. Menylänkarna är inaktiva (demo).

- `index.html` – rubriker i Instrument Serif, brödtext i Europa
- `charm-typsnitt.html` – samma sida med Charms nuvarande rubriktypsnitt (FF Market)

Öppna filerna direkt i webbläsaren eller via GitHub Pages.

Kaffevideon kommer från Pexels (fri licens). Logotyp, caféfoton och produktfoton tillhör Café Charm.
