# Café Charm – förslag på ny hemsida

Demo av en ny hemsida för Café Charm i Sundsvall.

- `index.html` – startsidan. Heron visar bullen; väljaren Bulle · Lunch · Tårta låter kunden prova de tre lägena.
- `bestall.html` – beställ & hämta: produkter från Charms sortiment, produktruta med storlek och önskemål, varukorg med val av café och hämtdag. Demo – ingen beställning skickas.
- `charm-typsnitt.html` – en äldre version med Charms nuvarande rubriktypsnitt (FF Market), inte uppdaterad.

Öppna via GitHub Pages eller direkt i webbläsaren.

Kaffevideon kommer från Pexels (fri licens). Logotyp, caféfoton och produktfoton tillhör Café Charm. Priser för större tårtstorlekar och allergener i shoppen är platshållare.
