# Café Charm – förslag på ny startsida

Demo av en ny startsida för Café Charm i Sundsvall.

- `index.html` – startsidan. Heron visar bullen; väljaren Bulle · Lunch · Tårta låter kunden prova de tre lägena. Länkar till sidor som inte finns än (shop, hela sortimentet) är inaktiva i demon.
- `charm-typsnitt.html` – en äldre version med Charms nuvarande rubriktypsnitt (FF Market), inte uppdaterad.

Öppna via GitHub Pages eller direkt i webbläsaren.

Kaffevideon kommer från Pexels (fri licens). Logotyp, caféfoton och produktfoton tillhör Café Charm.
